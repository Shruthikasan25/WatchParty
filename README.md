# WatchParty 🎬

WatchParty is a real-time web application that allows friends to watch videos together in a shared virtual room.

## Features

- Create and join watch rooms using a room code
- Synchronize video playback between participants
- Live chat between room members
- Emoji reactions
- Shared playlist
- Voting and leaderboard
- Countdown feature before watching together

## Technologies Used

- Python
- Flask
- Flask-SocketIO
- HTML
- CSS
- JavaScript

## Requirements

- Python 3.9 or later
- Flask
- Flask-SocketIO

## How to Run Locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   http://127.0.0.1:5000

## Note

WatchParty uses in-memory room data. Room information may be lost when the server restarts.
